# learning/

## Purpose
Stores notes, resources, and progress for each technology learning track from LEARNING_ROADMAP.md.

## Why This Exists
Learning compounds when you externalize your notes. A note taken today about how Lambda cold starts work becomes a reference next month when you are debugging a timeout. This directory is your personal technical library — built by you, for you.

## Industry Parallel
Senior engineers maintain personal knowledge bases. Teams maintain internal wikis (Notion, Confluence). This directory is your lightweight personal wiki for everything you learn on this journey.

## Recommended Structure

```
learning/
├── git-github/
```

## How to Use It
When you begin a new track from LEARNING_ROADMAP.md, create a subdirectory here. After each learning session, write 3–5 bullet points of what you learned. After a month, you will have a reference library you can actually search.
