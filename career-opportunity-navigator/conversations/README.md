# conversations/

## Purpose

Timestamped logs of every Claude Code session in this project — preserving decisions, evaluations, findings, and action items in full.

## Why This Exists

Claude session history is ephemeral. Subscription access may change. Every meaningful piece of analysis — opportunity evaluations, oracle findings, skill assessments, role decisions — is captured here so the work survives independent of any specific tool or subscription.

## File Naming

```
YYYY-MM-DD-session-NN.md
```

Multiple sessions on the same day use `-01`, `-02` suffixes.

## What Each Log Contains

- Session date and duration estimate
- Topics covered (indexed for scanning)
- Full decisions made with rationale
- Opportunity evaluation scores and oracle findings
- Action items with deadlines
- Key quotes and frameworks used
- Files created or modified

## How to Use This

Read the most recent log before starting a new session to re-establish context. If Claude loses your conversation history, paste the relevant session log back in and work continues with full context.
