# Career Preference Refiner & Opportunity Navigator

> An AI-powered career decision system built with Claude Code.

---

## What This Is

This agent continuously answers one question:

> "Of all the opportunities available to me, which best move me toward Cloud + AI + Product Leadership while maintaining marketability?"

It combines:
- A structured evaluation framework (scored, not just opinionated)
- A personalized learning engine (tied to real opportunities)
- A portfolio planning system (projects that build evidence)
- A preference refiner (gets smarter each week)

---

## Quick Start

Open this directory in Claude Code and say:

```
Evaluate this opportunity: [paste description]
```

Or:
```
What should I learn next?
```

Or:
```
Recommend a portfolio project
```

Or:
```
I want to do a weekly reflection
```
