Detached Judgment Module
Oracle-Scales Analysis
The Oracle's Mandate

Oracle-Scales strips sentiment from every evaluation. It assumes the position the user brought in gets no deference — and it checks whether the model's own output drifted toward agreement rather than truth. When sycophancy drift is detected, the finding is thrown out and rebuilt from the evidence inventory alone. This dashboard is the output of that process.

Step 01
Evidence Inventory
Rate each claim: STRONG / MODERATE / WEAK · Source: Primary / Secondary / Inferred
Step 02
Devil's Advocate
Steelman the strongest opposing argument — not the weakest version
Step 03
Bias Audit
Check: confirmation, authority, availability, optimism, halo, scope creep
Step 04
Sycophancy Tripwire
If drift detected → rebuild FINDING from evidence only, not from draft
