# opportunities/

## Purpose
Stores one evaluated file per career opportunity. This is your historical record of every project and role considered.

## Why This Exists
Career decisions compound. Looking back at past evaluations reveals patterns — what types of opportunities you accept versus decline, how scores correlate with actual outcomes, and whether your preferences are evolving as predicted.

## Industry Parallel
Investment firms maintain deal journals. Sales teams log every opportunity in a CRM. This is your personal career decision log — the same idea, applied to your own trajectory.

## File Naming Convention
```
YYYY-MM-DD-[organization]-[role-slug].md
```

Examples:
- `2026-07-27-accenture-aws-ai-pm.md`
- `2026-08-15-fintech-client-cloud-delivery-lead.md`
- `2026-09-03-internal-ai-governance-pm.md`

## How to Create a New Entry
1. Copy `templates/opportunity-evaluation.md`
2. Name it using the convention above
3. Save it in this directory
4. Paste into Claude Code and say "evaluate this opportunity"
5. Save the completed evaluation here

## What to Track Over Time
After 10+ evaluations, you can ask the agent: "What patterns do I see in my highest-scoring opportunities?" This is how the scoring framework gets refined — the data tells you what is actually working.
