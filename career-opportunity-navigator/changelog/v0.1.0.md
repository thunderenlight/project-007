## Key Decisions Made in v0.1.0

1. **File-based architecture first** — Establish reasoning logic before adding infrastructure. Evolve when the use case is proven. Pattern: evolutionary/walking skeleton architecture.

2. **Claude Code as the primary interface** — Conversational evaluation via Claude Code before building a custom UI (Phase 5). Faster to validate the reasoning engine before building a wrapper around it.

3. **10-dimension scoring** — Comprehensive enough to capture nuance, simple enough to complete in one session without cognitive overload.

4. **7-phase project roadmap** — Each phase teaches a new technical domain. The build process itself is the education. Phases were ordered so each one builds on the previous.

5. **8-track learning roadmap** — Each track is tied to the build (every track produces a portfolio artifact from this project). Learning and building are not separate activities.

6. **Subfolder architecture** — Lives inside the existing workspace. Can be extracted to its own repo when Phase 4 (API integration) begins and the project needs its own Git history.

7. **ADRs in architecture/** — Document why decisions were made now, while the context is fresh. The future self and any future collaborators will want to know.
