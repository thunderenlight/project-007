# role-targeting/applications/

## Purpose
Tracks the lifecycle of active applications and pursuits — from first contact to decision.

## Why This Exists
Most opportunities are lost not because of poor fit, but because of poor follow-through. This directory makes follow-through systematic — you always know where each opportunity stands and what the next action is.

## Industry Parallel
Sales teams use CRM pipelines. Recruiters use ATS (Applicant Tracking Systems). This is your personal career pipeline — lightweight but deliberate.

## File Naming Convention
```
YYYY-MM-DD-[organization]-[role-slug]-application.md
```

## Application Status Pipeline

```
Identified → Researched → Applied / Expressed Interest → Screening → Interview → Decision
```

At each stage, document what happened and what comes next.
