# role-targeting/evaluations/

## Purpose
Full scout reports for roles you are actively considering or pursuing — generated by `skills/project-opportunity-scout.md`.

## Why This Is Separate from opportunities/

| `opportunities/` | `role-targeting/evaluations/` |
|-----------------|-------------------------------|
| All evaluated opportunities, including ones you passed on | Only roles you are actively pursuing or seriously considering |
| Compact evaluation with scores and learning plan | Full 5-part scout report (score + gaps + networking + learning + interview prep) |
| Discovery and triage | Active pursuit and preparation |

Think of `opportunities/` as your discovery log and `role-targeting/evaluations/` as your active dossier.

## File Naming Convention
```
YYYY-MM-DD-[organization]-[role-slug]-scout.md
```

Examples:
- `2026-08-01-fintech-client-ai-pm-scout.md`
- `2026-08-15-accenture-internal-genai-lead-scout.md`

## How to Create an Entry
1. Paste the opportunity into Claude Code (job posting, staffing request, role description)
2. Say: "Run the opportunity scout on this"
3. The agent runs `skills/project-opportunity-scout.md` automatically
4. Save the output here using the naming convention above

## What a Complete Entry Contains
- Part 1: Fit Score (10 dimensions + hard rules check)
- Part 2: Skill Gap Analysis (blocking, differentiating, supporting)
- Part 3: Networking Action Plan (3–5 contacts with outreach drafts)
- Part 4: Learning Plan (7-day immediate + 30/60/90-day sprint)
- Part 5: Interview Prep Kit (questions, talking points, portfolio stories, red flags)
